# 智阅教育 项目增强建议

> 基于全项目审计，共发现 80 项可改进点。以下按优先级分组总结。

---

## 🔴 第一优先级：安全（不可忽略）

即使作为课程项目，这些也需要修复，否则评审老师一眼就能看出来。

| # | 问题 | 位置 | 修复方案 |
|---|------|------|----------|
| 1 | 密码明文存储，直接字符串对比 | `AuthService.java:41` / `Teacher.java:11` | 引入 BCrypt 加密存储和验证 |
| 2 | API Keys 明文写在 yml 里 | `application.yml:33-42` | 用 `${ENV_VAR}` 环境变量替代 |
| 3 | 管理员账号密码硬编码 `admin/admin123` | `AdminService.java:71` | 至少放配置文件，密码加 BCrypt |
| 4 | JWT 密钥硬编码，有效期 30 天过长 | `application.yml:25-26` | 用环境变量，有效期改 7 天 |
| 5 | CORS 配了 `*` + `allowCredentials(true)` | `CorsConfig.java:12` | 去掉 `allowCredentials` 或限制具体域名 |
| 6 | 管理员鉴权仅靠 `teacherId != 0L` | `WebConfig.java:63` | 增加角色字段 `role`，区分 teacher/admin |
| 7 | 无任何限流保护 | 全项目 | 加一个简单的 IP 限流拦截器 |

## 📊 建议实施路线

| 阶段 | 内容 | 约需时间 |
|------|------|----------|
| **即改（课程答辩前）** | BCrypt 加密 + API Key 环境变量 + CORS 修复 | 2-3 小时 |
| **短期（答辩演示加分）** | 导出 Excel + 班级统计页 + 作业编辑功能 + 教师注册 | 1-2 天 |
| **中期（产品化）** | 分页 + 限流 + 测试覆盖 + 微信支付打通 | 1-2 周 |
| **长期（上线准备）** | 后台重构 + 通知系统 + 题库打通 + 学校集采版 | 1-3 月 |

---

## 🎯 最推荐先做的 5 件事

1. **BCrypt 密码加密**（10 分钟，直接消除最大安全槽点）
2. **环境变量管理秘钥**（5 分钟，yml 改 `${}` 占位）
3. **作业编辑功能**（30 分钟，加一个 PUT 接口）
4. **导出 Excel**（1 小时，Apache POI，后加一个下载按钮）
5. **班级分数统计页**（1-2 小时，/api/stats/class/{id}）

这 5 件事加起来不超过半天，能让项目在答辩时从 "课程项目" 直接升到 "有产品潜力的毕业设计"。
